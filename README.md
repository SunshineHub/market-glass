# 澄明行情（Market Glass）

面向 macOS 与 Windows 的本地基金与全球大盘信息桌面应用。

当前已完成第一版可运行工程骨架：Vue 双窗口、Tauri 命令层、Rust 领域计算、三级基金估值适配器和 SQLite 本地持久化均已落地。

## 当前可用能力

- `1180 × 760` 主窗口与 `420 × 300` 极简窗口。
- 跟随系统明暗的玻璃材质；原生材质不可用时自动使用 CSS 高可读降级效果。
- 隐私模式隐藏全部金额，同时保留当日盈亏率与总盈亏率。
- 手动添加基金和现金管理资产。
- 单项与批量新增均允许份额、成本为 0；同一基金代码会累计份额与投入金额，可只添加为行情观察项。
- 批量导入“自选基金助手”3.x JSON 配置：先生成可编辑预览，再以单个 SQLite 事务提交。
- 覆盖 16 个中国、美国、香港、欧洲与亚太主要指数（东方财富异常时回退新浪）；总览可自选 1–4 个指数，大盘页可独立添加或移除指数。
- 基金按“新浪盘中估值 → 披露持仓加权估算 → 东方财富确认净值”降级。
- SQLite 持久化与主/极简窗口事件同步；后台默认每 60 秒合并刷新。
- 独立“资产分析”页面展示行业/策略分布与数据覆盖；基金页支持按当日涨跌幅排序。
- 资产列表支持流畅滚动、批量选择删除与清空；所有删除均需二次确认。
- 点击资产名称可覆盖修改单项持仓；勾选多项后可批量修改份额、成本和行业分类。批量修改逐项独立写入，失败项留在弹窗并显示原因，其他项目照常保存。
- 资产列表通过“当日盈亏”表头的小三角直接切换涨跌幅排序，金额与比例分两行显示。
- 资产列表可导出可再次导入的 JSON 持仓备份；桌面版保存到系统下载目录，重名文件自动追加序号。
- macOS 使用系统红黄绿窗口按钮和原生圆角；关闭只隐藏窗口并保留后台刷新，Windows 使用可点击的自绘窗口控制。
- 极简窗口使用贴合原生圆角的单层玻璃表面，不再额外套一层矩形蒙版。
- macOS 菜单栏与 Windows 系统托盘使用独立模板图标，支持打开双窗口、立即刷新和安全退出；macOS 菜单栏图标旁常驻显示今日盈亏比例。

## 本地运行

```bash
pnpm install
pnpm tauri:dev
```

只调试界面（使用脱敏模拟数据）：

```bash
pnpm dev
```

前端校验：`pnpm typecheck && pnpm build`。Rust 校验：`cargo test --workspace`。

调用真实公开行情做一次集成检查：

```bash
cargo test -p market-glass-providers live_provider_returns_global_indices_and_a_fund_snapshot -- --ignored
```

生成当前系统安装包：`pnpm tauri build`。macOS 输出 `.app/.dmg`，Windows 输出 NSIS/安装包；正式对外发布还需分别配置 Apple 签名公证和 Windows 代码签名。

仅编译不打包：`pnpm tauri build --no-bundle`，产物位于 `target/release/market-glass-desktop`。

Windows 可通过 GitHub Actions 自动生成 NSIS `setup.exe`；操作见 [Windows 自动打包与分发](docs/WINDOWS_RELEASE.md)。

## 导入说明

主窗口“资产列表”右上角选择“添加 / 导入”：

1. “配置导入”支持自选基金助手 3.x 导出的 JSON；默认只勾选有持有份额的项目。
2. 文件解析后先进入可编辑预览，不会读取后直接写库。
3. 优先读取 `fundListGroup`、`fundListM`、`fundList` 中的真实配置；`dataList` 只作为名称元数据，不会再被误当成额外持仓。
4. 份额或成本为 0 的条目可手动勾选为观察项；没有成本的基金不会把全部市值误算为累计盈利。
5. 新增已存在的基金代码时累计份额与投入；点击列表中的基金名称编辑时使用覆盖语义。
6. 批量提交失败时整个批次回滚，导入原文件不会被修改。

这里的“整个批次回滚”只针对配置文件导入；资产列表中的“批量修改”采用逐项独立保存，单项失败不会影响其他修改。

点击资产列表右上角“导出配置”会按当前可见基金生成 JSON 备份，保留份额、累计成本和行业/策略分组；导出的 `totalCost` 字段用于无损回导，同时保留自选基金助手兼容的单份成本字段。

## 设计目标

- 一套代码同时支持 macOS 和 Windows。
- 主窗口用于完整资产管理，极简窗口用于日常快速查看。
- 以基金资产和全球市场观察为核心，不做券商交易终端。
- 本地优先、金额可隐藏、数据新鲜度必须可见。
- 行情源和系统视觉效果都可以替换或降级。
- 数据库、接口和发布过程支持长期版本迁移。

## 当前关键假设

1. 主资产为公募基金；现金管理仅作为辅助记录。
2. 基金盘中数据是估值而非正式净值；接口失效时按三级策略降级并明确标记。
3. 雪球、且慢账户没有稳定且获授权的个人组合持仓接口，因此产品不展示不完整的“投顾组合”功能；底层兼容字段仅用于保护旧数据。
4. 极简窗口不展示任何基金或持仓明细。
5. 隐私模式隐藏所有金额，但始终显示当日盈亏百分比和总盈亏百分比。
