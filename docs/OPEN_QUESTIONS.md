# 待确认事项

这些问题不阻塞架构文档，但会影响具体实现顺序和发布配置。

## 1. macOS 发布渠道

需要确认是否必须进入 Mac App Store。

- 官网/GitHub 下载：可以采用更完整的透明窗口和 Vibrancy 路线，并进行 Developer ID 签名与公证。
- Mac App Store：需要避开影响审核的 private API，玻璃效果应使用商店兼容的材质降级方案。

无论选择哪一种，核心功能和数据层保持一致。

## 2. Windows 最低版本

建议正式支持 Windows 11，并对 Windows 10 22H2 提供兼容支持。如果用户设备全部为 Windows 11，可以减少 Acrylic 兼容成本。

## 3. 初始数据迁移

需要确认是否从现有 Chrome 插件导入：

- 基金代码
- 份额
- 成本价/累计投入
- 分组

如果需要，Phase 1 提供一次性导入器，原插件数据不会被修改。

## 4. 数据备份

首版默认仅提供本地加密备份文件，不提供云同步。未来若需要多电脑同步，再独立设计加密、冲突合并和账户体系。
