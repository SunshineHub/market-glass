# 产品设计

## 1. 产品定位

“澄明行情”是个人使用的跨平台资产观察工具，重点解决三件事：

1. 汇总基金资产、成本和收益。
2. 在数据源能力允许时更新基金估值和最新净值。
3. 通过一个小巧、可隐藏金额的桌面窗口快速查看收益率和大盘状态。

它不是下单软件，也不提供交易建议。第一阶段不接入券商交易能力。

## 2. 窗口模型

### 2.1 主窗口（A）

建议初始尺寸为 `1180 × 760`，最小尺寸为 `980 × 680`。

导航结构：

- 总览
- 资产分析
- 基金
- 大盘
- 设置

总览页面包含：

- 可编辑的 1–4 个自选主要指数。
- 资产概览：总资产、当日盈亏、总盈亏及对应百分比。
- 资产列表：基金资产集中展示，并支持批量删除、清空和滚动浏览。

资产分析页面包含：

- 按“行业 / 策略标签”聚合的行业比例；未填写标签时按基金名称归类。
- 基金、资产条目、行情覆盖和 0 份额观察项数量。
- 明确的统计口径说明，不把 0 金额观察项计入金额占比。

基金行展示：

- 基金名称与代码
- 最新净值或估值
- 持有金额
- 当日盈亏金额和百分比
- 总盈亏金额和百分比
- 精简的数据来源胶囊与更新时间；跨日数据同时显示日期

### 2.2 极简窗口（B）

建议尺寸为 `420 × 300`，支持置顶、拖动和记忆位置。

极简窗口不展示基金或持仓明细，只展示：

- 四个主要指数及迷你趋势图
- 当日盈亏百分比
- 总盈亏百分比
- 数据更新时间和刷新状态

资产可见模式额外展示：

- 总资产金额
- 当日盈亏金额
- 总盈亏金额

隐私模式隐藏：

- 总资产金额
- 所有盈亏金额
- 任何账户或资产明细

隐私模式始终保留：

- 当日盈亏百分比
- 总盈亏百分比
- 大盘指数

### 2.3 系统托盘/菜单栏

- macOS 菜单栏与 Windows 系统托盘使用同一行为模型。
- 单击图标：显示或隐藏极简窗口。
- “打开主窗口”：切换到完整资产管理。
- “立即刷新”：触发一次合并刷新。
- “隐私模式”：与极简窗口眼睛按钮同步。
- 关闭窗口不退出程序；从托盘菜单执行“退出”才结束进程。

## 3. 颜色与玻璃效果

- 默认跟随系统浅色/深色外观，不提供独立主题开关。
- 正收益使用珊瑚红，负收益使用玉绿色，符合国内行情习惯。
- macOS 优先使用 Vibrancy；Windows 11 优先使用 Mica；Windows 10 使用 Acrylic。
- 不支持系统效果或效果性能不佳时，回退为高不透明度材质，不影响信息阅读。
- 玻璃只是表现层，任何功能和信息层级都不能依赖透明效果。

## 4. 数据语义

每个数字必须带有下列数据性质之一：

- `实时`：证券或指数的实时行情。
- `估算`：根据盘中估值或底层资产估算。
- `已确认`：基金公司公布的正式净值。
- `手动`：用户输入或导入，但无法自动更新。

每个数字还必须有新鲜度状态：

- `正常`
- `延迟`
- `过期`
- `离线`

界面不得用旧数据冒充实时数据。刷新失败时保留最后一次成功结果，并明确显示更新时间和状态。

## 5. 收益计算

### 当日盈亏

```text
当日盈亏金额 = 当前估算资产 - 上一交易日确认资产 - 当日净流入
当日盈亏率   = 当日盈亏金额 / 调整后的上一交易日资产
```

### 总盈亏

```text
总盈亏金额 = 当前资产 - 累计净投入成本
总盈亏率   = 总盈亏金额 / 累计净投入成本
```

当资产没有累计投入成本时，单项累计盈亏显示“未录入成本”；汇总累计盈亏只计算已录入成本的资产，并在卡片标题中明确口径。

申购、赎回、分红和费用必须作为交易流水进入成本计算，不能直接把资产变化当成收益。

### 平台组合能力边界

雪球、且慢等平台若不能通过官方授权接口或用户导出文件提供完整的个人组合持仓，本产品不展示投顾组合菜单，也不使用手工总金额模拟组合收益。旧版本写入的兼容记录保留在本地数据库中，但不会进入当前资产统计。

## 6. 无障碍与可用性

- 颜色不是唯一信号，涨跌同时使用正负号和文字。
- 支持系统缩放、键盘导航和减少动态效果。
- 金额使用等宽数字，避免刷新时布局抖动。
- 极简窗口在小屏和多显示器下记忆各自的位置。
