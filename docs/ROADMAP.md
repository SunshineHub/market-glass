# 迭代路线

路线以“每一阶段都可独立使用”为原则，不先搭建大而全的空框架。

## Phase 0：工程骨架与技术验证

目标：证明跨平台窗口、数据和发布链路可行。

- 建立 Tauri 2 + Vue 3 + TypeScript + Rust workspace。
- 建立 `domain/application/infrastructure/providers` 分层。
- 实现主窗口、极简窗口和托盘的空壳。
- 验证 macOS Vibrancy、Windows 11 Mica 和降级材质。
- 建立 SQLite 迁移、日志、IPC 类型和 CI。
- 用固定假数据完成双窗口和隐私规则测试。

验收：macOS 和 Windows 均能启动、切换窗口并正确隐藏金额但保留两项收益率。

当前进度（0.1.0）：工程分层、双窗口、隐私规则、SQLite 与 IPC 已实现；macOS Release 二进制已通过本机编译和启动验证，Windows 真机材质与安装包验证仍待执行。

## Phase 1：基金与大盘 MVP

- 手动新增基金、份额、成本和交易流水。
- 获取全球主要股票市场指数，并允许编辑总览自选指数。
- 获取基金最新净值；数据源提供时显示盘中估值。
- 计算当日盈亏、总盈亏及百分比。
- 完成 A/B 窗口、明暗模式、离线缓存和手动刷新。
- 支持从现有浏览器插件配置导入基金。

验收：公共行情异常时不丢失持仓，且所有数据明确标注性质和时间。

当前进度：0 份额观察资产、重复基金累计、16 个全球指数、可编辑总览指数、三级基金估值、盈亏计算、60 秒后台刷新和自选基金助手 3.x 配置批量导入已实现；交易流水与离线行情快照尚未实现。

## Phase 2：分析与提醒

- 更精细的行业穿透、资产历史、收益曲线和策略分布。
- 区分投资收益与资金流入流出。
- 数据延迟、净值更新和异常波动提醒。
- 可配置极简窗口布局。

## Phase 3：发布与长期维护

- macOS 签名、公证与 Windows 代码签名。
- 签名自动更新。
- 脱敏诊断导出和崩溃恢复。
- 根据需要增加加密备份或用户主动开启的同步。

## 暂不进入首版

- 交易下单和券商账户控制。
- 自动抓取需要绕过登录或验证码的平台。
- 未经用户确认上传资产数据。
- 用历史净值冒充实时估值。
- 在所有投顾来源未确认前实现平台专用爬虫。
- 用手工总金额冒充投顾底层组合或自动收益。
